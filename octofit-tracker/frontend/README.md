# OctoFit Tracker Frontend

React 19 presentation tier for OctoFit Tracker.

## Environment

In GitHub Codespaces, define `VITE_CODESPACE_NAME` in `.env.local`:

```dotenv
VITE_CODESPACE_NAME=your-codespace-name
```

When the variable is unset, the frontend connects to `http://localhost:8000`.

## Development

```bash
npm run dev --prefix octofit-tracker/frontend -- --host 0.0.0.0
```
